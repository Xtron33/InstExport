# Выпуск версии

GitHub Actions запускает CI для каждого pull request и push в ветку: проверяет форматирование, типы, ESLint, тесты и сборку UXP-плагина.

Чтобы подготовить релиз:

1. Измените версию одновременно в `package.json` и `manifest.json` и дождитесь успешного CI в основной ветке.
2. Создайте и отправьте тег того же коммита в формате `v<версия>` (например, `v0.1.0`). Workflow `Release candidate` повторит проверки, соберёт `InstExport-<версия>.ccx`, проверит содержимое архива и создаст черновик GitHub Release с `.ccx` и файлом `.sha256`.
3. Установите `.ccx` из черновика через Adobe Creative Cloud. Проверьте открытие панели, оба режима экспорта и реальные JPEG-файлы в Photoshop.
4. После ручной проверки опубликуйте черновик релиза в GitHub. Ссылка `releases/latest` в README начнёт вести на опубликованную версию.

Если черновик для тега уже существует, повторный запуск обновит его файлы. Опубликованный релиз workflow не перезаписывает. Публикация намеренно остаётся ручной, поскольку CI не может проверить работу плагина внутри Photoshop.
