# Установка и проверка InstaSaver 0.1.0

## Статус проверки

Проверено в окружении разработки:

- TypeScript: проверка типов без ошибок.
- 13 тестов Vitest: геометрия и граничные пропорции, поля, число слайдов, точное покрытие полосы квадратами, очистка копий при сбое и отмене, список уже сохранённых файлов, конфликты имён, жизненный цикл React 19 root (повторное открытие, скрытие и уничтожение панели). Запуск: `yarn run test`, наблюдение: `yarn run test:watch`.
- React-панель проверена в браузере с имитацией Photoshop: переключение режимов, обновление активного документа, отмена/подтверждение замены, отчёт о сохранении, ширина панели 300 px. Это не проверка UXP-рендерера.
- `dist/` собирается Vite; локальный архив `release/InstExport-0.1.0.ccx` упаковывается из этой же сборки. Vite проверяет HTML-точки входа и пути JS/CSS для корневого и собранного манифестов.

Пока не проверено в Photoshop: загрузка панели, фактические JPEG, белый фон, профиль, отмена модальной операции и установка CCX. На момент разработки Photoshop не был запущен. Установленная версия на компьютере — 27.10; заявленная минимальная версия плагина — 25.0.0 по используемым API.

## Загрузка для разработки

1. Запустить Photoshop. В Preferences → Plugins включить Developer Mode, если требуется; применить запрос на перезапуск.
2. Запустить Adobe UXP Developer Tools и включить Developer Mode в нём. Photoshop должен появиться среди подключённых приложений.
3. Add Plugin → выбрать `dist/manifest.json` → Load.
4. Открыть панель InstaSaver из меню Plugins. Если загрузка не удалась, открыть Debug / журнал в UXP Developer Tools и сохранить текст ошибки.
5. При изменениях выполнить сборку и Reload в UXP Developer Tools. Перед перезагрузкой дождаться завершения экспорта.

Для ручной упаковки средствами Adobe можно использовать действие Package в UXP Developer Tools. Локальный `.ccx` проекта — ZIP-пакет с манифестом в корне, не публикация в Marketplace. Для публикации потребуется зарегистрированный Adobe plugin ID; текущий ID предназначен для локальной разработки.

### Ошибка `Cannot resolve module: index.html`

В первоначальной структуре корневой манифест ссылался на отсутствующий корневой HTML. Теперь добавлен `index.html`, загружающий сборку из `dist/`; оба манифеста можно использовать в UXP Developer Tools. Сборка проверяет наличие HTML и связанных JS/CSS для обоих вариантов. После обновления выполнить Unload → Load. При сохранении ошибки удалить запись плагина из списка UXP Developer Tools и заново добавить `E:\Work\InstaSaver\dist\manifest.json`.

## Проверка трёх режимов

Сначала выбрать отдельную тестовую папку и открыть копии тестовых фотографий.

| Исходник / режим            | Ожидаемый результат                                                              |
| --------------------------- | -------------------------------------------------------------------------------- |
| 6000 × 4000 / Универсальный | 1080 × 720, без полей                                                            |
| 4000 × 5000 / Универсальный | 1080 × 1350, без полей                                                           |
| 4000 × 2000 / Универсальный | Холст 1080 × 566, изображение 1080 × 540, поля сверху/снизу по 13                |
| 2000 × 3000 / Универсальный | Холст 1080 × 1440, изображение 960 × 1440, поля слева/справа по 60               |
| 800 × 1000 / Универсальный  | 800 × 1000, без увеличения                                                       |
| 6000 × 4000 / На фоне 3:4   | Холст 1080 × 1440, изображение 1080 × 720, поля сверху/снизу по 360              |
| 4000 × 2000 / Панорама      | Полная версия 2160 × 1132 с полями сверху/снизу по 26 и два квадрата 1080 × 1080 |
| 6000 × 2000 / Панорама      | Полная версия и три квадрата                                                     |
| 5000 × 2000 / Панорама      | Полная версия и три квадрата; на полосе белые поля слева/справа по 270           |

Для проверки стыков использовать изображение с линиями и отметками у краёв, расположить квадраты рядом в порядке суффиксов. Проверить отсутствие пропуска, повторения пикселей и дополнительного сдвига по центру. При нечётных размерах поля могут отличаться на один пиксель. У полной панорамы и полосы для нарезки независимые поля.

## Цвет, документы и ошибки

- Проверить RGB 8/16 бит, CMYK, Lab и Grayscale. Проверить выходной JPEG: RGB, 8 бит, встроенный sRGB.
- Проверить изображение с прозрачностью и несколько слоёв; видимый результат должен совпасть с оригиналом на белом фоне.
- Перед тестом выбрать в Photoshop яркий цвет фона, например красный. Поля экспорта должны оставаться белыми; цвет фона Photoshop не должен измениться.
- Проверить исходное выделение и активный дополнительный канал: они не должны влиять на экспорт и не должны измениться в оригинале.
- Изменить масштаб просмотра и включить линейки в сантиметрах: расчёт остаётся в пикселях.
- После экспорта убедиться, что размеры, слои, профиль и состояние сохранения исходника не изменились, временные документы закрыты.
- Повторить экспорт: панель должна предложить замену существующих файлов. Отмена не меняет их.
- Проверить отказ доступа к папке и отмену через Photoshop: показывается ошибка/отмена и список файлов, успевших сохраниться. Операция из нескольких файлов не атомарна.

## Ограничения первой версии

- 32-битные HDR, Bitmap, Indexed Color, Duotone, Multichannel, монтажные области и неквадратные пиксели не поддерживаются; панель сообщает об этом при экспорте.
- Поддерживается активный документ, не пакетная обработка папки.
- Фон белый, качество JPEG фиксировано 12/12. Нет целевого размера файла в МБ.
- Папка запоминается на время работы панели; выбранный режим сохраняется между запусками. Папка выбирается пользователем через UXP picker.
- При ошибке кодирования JPEG существующий файл не затрагивается: сначала кодируется временный файл. Само копирование в папку назначения и замена не являются атомарной транзакцией.
- Пропорции обычных постов настроены на 3:4…1,91:1. Instagram может менять правила, сжимать изображение и иначе показывать миниатюру. Нужна отдельная тестовая публикация.
- При нарезке более 20 квадратов панель напоминает проверить лимит карусели; экспорт не ограничивается этим числом. Полная панорама и квадраты в одной карусели могут кадрироваться приложением Instagram.

## API-решения

Использованы [Photoshop Document API](https://developer.adobe.com/photoshop/uxp/ps_reference/classes/document/), [JPEGSaveOptions](https://developer.adobe.com/photoshop/uxp/2022/ps-reference/objects/saveoptions/jpegsaveoptions) и [executeAsModal](https://developer.adobe.com/photoshop/uxp/2022/ps-reference/media/executeasmodal).

Размеры, профиль и сохранение реализованы через DOM. Заливка и расширение холста — через `batchPlay`: для холста явно задан белый `canvasExtensionColorType`, чтобы не зависеть от глобального цвета фона Photoshop. Холст расширяется относительно центра без последующего перемещения. Временные документы регистрируются для автоматического закрытия при завершении модального контекста, включая отмену.
